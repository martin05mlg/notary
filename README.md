# Notary

> **Nota:** Este repositorio es un enlace de referencia en mi perfil personal. El proyecto principal se desarrolla en la organización **[notary-dev](https://github.com/notary-dev/notary)**.

## Descripción

**Notary** es una herramienta CLI educativa para firmar y verificar documentos con el DNIe español (CAdES-T/LT, PAdES, RFC 3161).

🔗 **Repositorio principal:** [https://github.com/notary-dev/notary](https://github.com/notary-dev/notary)
